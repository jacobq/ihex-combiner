# ihex-combiner


## Build command

```
$ dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true -p:UseAppHost=true
# Should create "IntelHexCombiner\bin\Release\net8.0\win-x64\publish\IntelHexCombiner.exe"
```
